# Changelog

## 1.4.2

- Full reimplementation of the Windows `netsh interface portproxy` manager
  with mygo's native UI.
- Dark desktop sidebar with group management, status/type filters, live
  search and pagination.
- Inline enable/disable switches, dedicated aligned Actions column, and a
  confirmation dialog before deleting rules.
- English and 简体中文 interface, light and dark themes.
- Signed auto-updates from GitHub Releases; in-place overwrite installs.
- Windows-only: single instance, elevated on launch, quits on window close.
